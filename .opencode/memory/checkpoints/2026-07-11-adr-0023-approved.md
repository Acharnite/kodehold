## Decisions
- 4 DP standards codified:
  - **DP-1: Exception Specificity** — bare `except:` / `except Exception:` prohibited; specific types required
  - **DP-2: Storage Layer Logging** — every TradingDB write emits DEBUG on success, ERROR on failure
  - **DP-3: Storage Abstraction Boundary** — `_conn.execute()` only in `db.py`; public methods for all access
  - **DP-4: Explicit Transaction Control** — multi-statement writes use `with self._conn:` for atomicity
- ADR-0023 maps directly to ADR-0018 findings: P0.1→DP-1, P0.2→DP-2, P0.3→DP-3, multi-stmt→DP-4
