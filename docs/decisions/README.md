# Design Decisions — Working Notes

This directory contains working notes, options analysis, and trade-off explorations that lead to formal Architecture Decision Records (ADRs).

## Convention

- Files here are **drafts** — they document the thinking process before a decision is finalized
- Once a decision is mature, it is formalized as an ADR in `docs/adr/`
- Working notes may be superseded or deleted; ADRs are permanent
